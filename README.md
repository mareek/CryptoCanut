# CryptoCanut

An amateur command line tool to encrypt and decrypt files (using AES for encryption and PBKDF2 for password hashing)

> [!WARNING]
> I'm not a security expert, there may be some vulnerabilities

## Usage

`CryptoCanut encrypt [FilePath]` to encrypt a file.

`CryptoCanut decrypt [FilePath]` to decrypt a file.

Type `CryptoCanut --help` in the command line for the full documentation.
